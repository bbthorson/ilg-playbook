# The Consensus Motion

Motion: **Consensus-led**. Structural level, consensus-dominant direction.

**This directory is nearly empty, and that is the finding rather than an oversight.**

Consensus-dominant is a routing destination. The [Deal Triage Calculator](../deal-triage-calculator.md) will send deals here, and when it does, the instruments waiting for them are one calculator and two sections borrowed from other motions. That is not a motion. This file exists so the gap is visible in the file tree instead of being discovered by a rep at a forecast call.

---

## What the component is

The cost of getting the buyer's own organization to agree. The pair is the buyer's stakeholders against each other, and the thing they cannot see is what the others are measured on.

**Nothing the seller knows and withholds is causing it.** Two stakeholders whose incentives conflict are not separated by an information gap the seller could close with a better demonstration. The problem is happening inside the buyer's building, on objectives the seller mostly cannot observe, and it still arrives on the seller's forecast as a stalled deal.

That asymmetry is why this component resists the instruments that work on the other two. A costly signal reduces what the buyer does not know about the seller. It does nothing for what the buyer's finance lead does not know about the buyer's operations lead.

## What exists today

| Asset | What it does | What it does not do |
|---|---|---|
| [Consensus Friction Calculator](../consensus-friction-calculator.md) | Sizes $F_{consensus}$ from committee size, incentive variance and technical overlap | Produces a number and then prescribes executive sponsorship, which is one tactic |
| [Contextual Blueprint](../implementation-motion/01-discovery-contextual-blueprint.md), political map section | Identifies who loses budget, headcount or control if the deal closes | Sits inside an implementation instrument, so it runs only when that motion runs |
| [Red Team Protocol](../implementation-motion/02-validation-red-team-protocol.md) | Surfaces objections in a room, including from a named skeptic | Same. Built to test implementation risk, and it catches stakeholder conflict as a side effect |
| [Deal Triage Calculator](../deal-triage-calculator.md), consensus block | Counts veto holders and how many have a documented measured objective | Measures the gap. Does not close it |

Every row measures. None of them is an instrument the seller deploys to reduce the cost.

## Where the incumbent practice actually lives

The wider sales profession has worked this component hard, under other names. Qualification frameworks built around economic buyer access, written decision criteria, documented decision process and champion development are consensus instruments, and they are the incumbent practice.

This repository does not carry them, and a rep routing here should reach for them and say on the forecast call that they are working outside the framework. Substituting the implementation chain because it is the one that exists is the failure this file is trying to prevent, and it is the natural move because the implementation chain is well built and available.

Research on why the component behaves the way it does is in [buying-center-dynamics.md](../../../theory/02-research/buying-center-dynamics.md).

## What an instrument here would have to do

Recorded so that building one starts from a specification rather than from a blank page. Each of these follows from something the framework already establishes.

**Score from measured objectives, never stated positions.** Stated positions converge under social pressure and measured objectives do not, so a committee where nobody voices dissent is as consistent with suppressed variance as with agreement. Any instrument that collects opinions in a room containing the room will understate the variance, and it will understate it most in the committees where the term matters most.

**Give each stakeholder something to lose.** Axiom III says an adjudicator without a stake drifts toward extraction. A stakeholder who can veto and carries no consequence for vetoing is exactly that, and no amount of alignment work reaches them.

**Survive the champion leaving.** A departed stakeholder is $\gamma_{consensus}$ arriving all at once, and it is the most common way a large deal dies. An instrument that produces alignment held in one person's head has produced nothing durable.

**Be affordable at the level it routes at.** Consensus-dominant deals sit above the boundary by definition, so the instrument can carry apparatus. It still has to amortize, which means frequency applies here the same way it does everywhere else. See [07-governance-forms.md](../../../theory/01-foundation/07-governance-forms.md).
