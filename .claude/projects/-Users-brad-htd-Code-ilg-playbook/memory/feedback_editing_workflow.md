For long-form co-editing sessions: use Sonnet throughout the drafting/iteration phase, then hand the completed draft to Opus for one final review pass before publishing.

**Why:** The back-and-forth drafting structure means editorial judgment is live in every exchange, not a discrete phase. Mid-session model handoffs add context-reload cost without much benefit. One Opus pass at the end is cleaner.

**How to apply:** Don't suggest switching models mid-draft. When all sections are landed and structure is right, flag that as the natural point to hand to Opus for final polish.
