Once the axiom restructuring is settled, do one propagation pass that:
1. Updates all downstream files (practice/, publishing/) to reflect the new axiom framing
2. Adds a "Theory basis" declaration to each downstream file (frontmatter or short header section) citing which axiom(s) it operationalizes — grep-able for future change impact

**Why:** Theory is still moving; adding dependency declarations now means doing it twice. The right moment is when the axiom reformulation is complete.

**How to apply:** Don't add a forward dependency map to the constitution until the axioms are finalized. When the restructuring is done, flag the propagation pass as the next task.
