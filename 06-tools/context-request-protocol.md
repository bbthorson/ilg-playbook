# Protocol: Context Request (The Scouting Report)

**Purpose:** To ensure the AI has all the information needed to produce "Conversational Intellectual" content that feels original and high-value.

Before analyzing or drafting, the AI should check if the following "Missing Context" would improve the quality of the output:

## 1. The "Hot Take" check
- Do you have a specific opinion on this event that contradicts the "market consensus"?
- Is there a "hidden hero" or "hidden villain" in this story we should highlight?

## 2. The Audience check
- Who is the primary reader for this specific piece? (e.g., "The Skeptical CIO," "The Overlooked Product Manager," or "The Venture Associate")
- What is their #1 pain point related to this topic?

## 3. The Evidence check
- Do we have any proprietary data or internal "game tape" (case studies, past experiences) that we can reference as a **Costly Signal**?
- Are there specific competitors who are running the "wrong play" in this scenario?

## 4. The Tone check
- Should this feel like a "Sobering Wake-up Call" or a "Quiet Technical Victory"?

---

**AI Instruction:** If a user provides a link or a topic, scan for these gaps. Do not ask for all of them every time—only ask for the ones that will meaningfully change the "Angle" of the analysis.
